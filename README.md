# Night Shift: AI Hospital

A psychological horror medical AI diagnosis game.

## 项目简介

玩家作为夜班实习医生，需要判断是否相信 AI 诊断系统。每一位病人的病历、AI 诊断建议和系统日志都可能暗示异常，玩家需要在信任、质疑和追加检查之间做出选择。

## 核心玩法

- 病例阅读
- AI 诊断
- 玩家决策
- Trust / Stress / Error 数值系统
- 多结局

## 特色

- 医学 AI 主题
- 病历自动篡改
- AI 终端打字机
- 心理恐怖氛围
- 纯前端实现

## 技术栈

HTML, CSS, JavaScript

## 如何运行

直接打开 `index.html`，或使用 GitHub Pages 部署后在线访问。

## GitHub Pages 部署步骤

Settings → Pages → Branch 选择 `main` → `root` → Save。
